# Deployment record

Fill this in **after** deploying and testing. Do not invent these values.

| Field | Actual value |
| --- | --- |
| Network | Pending deployment |
| Decimal chain ID | Pending deployment |
| Compiler version | Pending compilation |
| Contract address | Pending deployment |
| Custodian wallet (public address) | Pending deployment |
| Deployment transaction hash | Pending deployment |
| Successful add-item transaction hash | Pending test |
| Successful loan-request transaction hash | Pending test |
| Successful approval transaction hash | Pending test |
| Successful return transaction hash | Pending test |

Set `frontend/config.js` to the same contract address and chain ID. Paste transaction explorer links when using a public testnet. For Ganache, record visible local transaction hashes.
